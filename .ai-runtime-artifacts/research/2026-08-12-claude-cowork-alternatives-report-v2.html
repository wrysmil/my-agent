1 执行摘要

Claude Cowork 是 Anthropic 推出的 AI 桌面智能体产品，具备多模型对话、技能系统、沙箱隔离、MCP 协议集成等能力。本报告梳理了截至 2026-08-12 GitHub 上最活跃的 Claude Cowork 开源替代方案，按 Stars、功能完整度、架构设计、社区活跃度等维度进行评估。

当前生态中，Open Cowork（~2k stars）是最直接的 Claude Cowork 开源克隆；AQBot（779 stars）以 Tauri + Rust 轻量架构和 ACP 协议支持形成差异化；Abu-Cowork（273 stars）凭借自进化技能系统和多智能体并行能力在功能深度上最为突出。Wandesk（64 stars）则以 "AI 桌面 OS" 的范式突破引人注目。

5 技术栈与协议趋势

桌面框架

Electron（Open Cowork, Abu-Cowork）仍是当前最主流，生态成熟、开发效率高。Tauri（AQBot, Wandesk, ClickyX）因内存占用低、安装包小、性能好而迅速崛起。多数新项目首选 Tauri。

前端技术

React + TypeScript 是绝对主流。少数项目开始采用 React 19（Wandesk）和 Rust 为核心后端语言。

MCP vs ACP

MCP（Model Context Protocol）已被 Open Cowork、AQBot、Cherry Studio、Jan 等广泛采用。ACP（Agent Client Protocol）由 AQBot 率先支持，是智能体间通信的新兴标准。

本地化技术

AES-256 加密 API Key（AQBot）、本地 SQLite 存储（Wandesk）、sqlite-vec 向量数据库（AQBot）成为标配方案。Ollama 集成让纯本地推理成为可能。

📊 核心结论

  1. Open Cowork 是入口，Abu-Cowork 和 AQBot 是终点。 对于想体验 Claude Cowork 开源替代的用户，Open Cowork 最直接；对于追求功能深度和本地安全的开发者，Abu-Cowork 和 AQBot 提供了更差异化的价值。
  2. Tauri 正在取代 Electron 成为 AI 桌面应用的首选框架。AQBot、Wandesk 均采用 Tauri，安装包更小、资源占用更低。
  3. MCP 已成为标配，ACP 是下一个前沿。 工具/智能体的标准化连接协议是生态互通的基础。
  4. 自进化技能系统（Abu-Cowork）代表了技能系统的演进方向——从人工定义到 AI 自主发现和固化。
  5. 本地优先 是不可逆的趋势。AES-256 加密、Ollama 集成、本地 RAG 正在成为标配能力。

🚀 技术选型建议

  • 新项目：优先 Tauri（Rust）而非 Electron，获得更好性能和小安装包
  • 架构设计：同时规划 MCP 和 ACP 双协议栈，确保工具和智能体的互操作性
  • 安全基线：API Key AES-256 本地加密 + 沙箱隔离 + 提示注入检测
  • 差异化方向：自进化技能系统（参考 Abu-Cowork）、Agent 工作台（参考 AQBot）、AI OS 范式（参考 Wandesk）
