# My Agent — 技术栈检测

## 运行时

| 组件 | 版本 | 用途 |
|------|------|------|
| **Electron** | ^33.4.11 | 桌面运行时（主进程 + 渲染进程） |
| **Node.js** | ~20.x（Electron 33 内置） | 主进程运行时 |
| **TypeScript** | ^5.7.0 | 主进程源码编译 |

## 核心依赖

| 包 | 版本 | 用途 |
|----|------|------|
| **better-sqlite3** | ^9.6.0 | SQLite 数据库（会话、配置、用量、Skills、Providers） |
| **zod** | ^3.24.0 | 配置 schema 校验 |
| **marked** | vendor/minified | Markdown 渲染（渲染进程） |

## 构建工具

| 工具 | 版本 | 用途 |
|------|------|------|
| **tsx** | ^4.0.0 | TypeScript 执行器（CLI chat 入口） |
| **vitest** | ^2.0.0 | 测试框架 |
| **electron-builder** | ^26.15.3 | 打包/分发 |
| **@electron/rebuild** | ^3.7.2 | Native 模块 ABI 重编译 |

## 架构分层

```
┌──────────────────────────────────────────────┐
│  Renderer (Vanilla JS + CSS)                 │
│  electron/renderer/                          │
│  ├── index.html    (四屏 SPA)                │
│  ├── js/app.js     (路由/导航)               │
│  ├── js/api.js     (IPC 封装)               │
│  └── js/pages/     (chat/sessions/settings/  │
│                      skills 页面)            │
├──────────────────────────────────────────────┤
│  Preload (CJS)                               │
│  electron/preload.cjs                        │
│  └── contextBridge → window.myAgent          │
├──────────────────────────────────────────────┤
│  Main Process (TypeScript → ESM)             │
│  ├── electron/main.ts (入口)                 │
│  ├── electron/main.cjs (CJS thin wrapper)    │
│  └── src/ipc/ (IPC 注册)                    │
├──────────────────────────────────────────────┤
│  Agent Core                                  │
│  ├── src/agent/    (AgentRunner + Session)   │
│  ├── src/tools/    (8 内置工具)              │
│  ├── src/providers/ (LLM Provider 抽象)      │
│  ├── src/prompts/  (System Prompt 模板)      │
│  ├── src/skills/   (Skill 加载器)            │
│  └── src/config/   (配置 schema + 加载)      │
├──────────────────────────────────────────────┤
│  Storage                                     │
│  └── src/storage/  (SQLite + JSONL + Crypto) │
└──────────────────────────────────────────────┘
```

## 关键版本约束

- Electron 33 内置 Node.js 20.x → ESM 支持需 `createRequire`
- better-sqlite3 是 native 模块 → 需要 `@electron/rebuild` 重编译
- TypeScript target ES2023, module NodeNext
- 渲染进程为纯 Vanilla JS（无 React/Vue/Svelte）
