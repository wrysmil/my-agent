# 前后端通信改造 — 上线检查清单 (M13)

## 灰度上线策略

### Phase 1: 灰度 1%
- **时间**: 上线后立即
- **范围**: 新用户 + 新会话
- **条件**: 无（首次灰度）

### Phase 2: 灰度 10%
- **条件**: 灰度 1% 稳定 24h
- **范围**: 所有用户 + 新会话

### Phase 3: 灰度 50%
- **条件**: 灰度 10% 稳定 48h
- **范围**: 所有用户

### Phase 4: 全量
- **条件**: 灰度 50% 稳定 72h
- **范围**: 所有用户

## 回滚条件

| 指标 | 阈值 | 回滚动作 |
|------|------|----------|
| 错误率 | > 1% | 回滚至上一阶段 |
| p99 延迟 | > 2s | 回滚至上一阶段 |
| WebSocket 连接失败率 | > 5% | 回滚至上一阶段 |
| 审批成功率 | < 95% | 回滚至上一阶段 |

## 监控指标

### 关键指标
```
# WebSocket 连接数
ws_connections_total

# 审批请求数
approval_requests_total
approval_approved_total
approval_rejected_total
approval_timeout_total

# 延迟
ws_frame_latency_ms{p99}
api_respond_latency_ms{p99}
```

### 告警规则
```yaml
- alert: WebSocketHighErrorRate
  expr: rate(ws_errors_total[5m]) / rate(ws_messages_total[5m]) > 0.01
  for: 5m

- alert: ApprovalTimeoutHigh
  expr: rate(approval_timeout_total[5m]) / rate(approval_requests_total[5m]) > 0.05
  for: 5m
```

## 回滚步骤

1. **紧急回滚**: 切换 feature flag → 旧协议
2. **数据保护**: 不删除 pending-store
3. **通知**: 发送回滚通知到钉钉群
4. **分析**: 48h 内输出故障报告
