子 Agent 调度渲染 v3.1

派发通知气泡 + 子 Agent 回复气泡（双气泡分离） 推荐方案
主 Agent · 紫色描边
派发通知气泡 · 绿色虚线 → 工作时实线 · 内嵌实时步骤
子 Agent 回复气泡 · 绿色实线 · coder 最终输出
⏱ 工作中脉冲

设计要点（v3.1 相对 v3 的关键差异）

  • 双气泡分离：派发瞬间创建"派发通知气泡 A"（绿色虚线，含 actor 头像 + "已派发 coder 子 Agent"）；coder 完成时创建"子 Agent 回复气泡 B"（绿色实线，含最终文本）
  • 派发通知气泡作为"工作中容器"：dispatch_started 时创建，coder 第一帧 SSE 到时切换为 working 态（虚线→实线 + 脉冲）；coder 完成时该气泡停止更新，由回复气泡 B 承载最终输出
  • 实时步骤展开在派发气泡 A 内：thinking / tool_call / tool_result 列表逐步 push，可点开看参数
  • 手收差异：
    • dispatch_to：主 Agent 后续可能再写收尾文本 → 回复气泡 B 是 coder 的最终输出，主 Agent 自己的收尾仍在主 Agent 气泡里
    • hand_off_to：回复气泡 B 标"最终回答" + 主 Agent 不再写收尾
    • run_worker：仅派发气泡 A（不创建回复气泡 B，因为子 Agent 不会输出可见文本）
  • 主 Agent trace 仍保留 dispatch_to 步骤（用户选 B）
