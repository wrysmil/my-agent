设计要点（v3 相对 v2 的关键差异）

  • 派发即时反馈：dispatch_to 进入执行 → 立即创建绿色"工作中"气泡（avatar + name + "子 Agent 回复" + 脉冲点 + "思考中…"）
  • 实时步骤展开：气泡内嵌 thinking / tool_call / tool_result 列表，每收到 SSE 帧就 push 一条 step（含 icon、label、参数/结果摘要）
  • typewriter 文本：worker text_delta → 实时 append 到气泡正文（不再等 run_worker tool_result 一次性显示）
  • 完成态：最后一个 step 标"已完成" + 脉冲消失 + 文本光标消失 + trace 默认折叠
  • 主 Agent trace 仍保留子 Agent 步骤（用户选 B）— 主 Agent 的 trace 气泡 + agent 气泡同时可见，互不干扰
  • 历史路径：刷新页面 → parseHistoryMessages + rebuildDispatchAgentMessages 从 tool_call + tool_result 派生 bubble + 一次性文本（保持兼容）
