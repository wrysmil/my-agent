设计要点（v3.3 — 与截图对齐的最终方案）

  • 派发通知由主 Agent trace bubble 自己承担：trace 里出现"派发 · dispatch_to · coder · ✓ 已派发"步骤就是通知，无需独立气泡
  • 主 Agent 派发后切等待态：背景变灰色虚线 + 状态切"等待 coder 回复"（脉冲灰色）· trace 步骤停在派发那一条
  • 派发完成 → 立即创建 coder 气泡（绿色头像 + "子 Agent 回复"标签） + coder 步骤实时展开（thinking / tool_call / tool_result） + typewriter 最终文本
  • coder 完成 → 主 Agent 重新激活（紫色脉冲 · "生成中…"）→ 写收尾文本到主 Agent 气泡
  • 手收差异：
    • dispatch_to：派发步骤 + 等待态 + coder 气泡 + 收尾
    • hand_off_to：派发步骤 + 等待态 + coder 气泡（标"最终回答"），主 Agent 切"已完成"不再写
    • run_worker：派发步骤 + 等待态 + coder 气泡（无文本回复 · 步骤完成后主 Agent 恢复）
